godot-lv2-host-example
======================

Simple example Godot project that uses [godot-lv2-host](https://github.com/nonameentername/godot-lv2-host/).

build
-----

1. Download depedencies
```
godot --headless -s package.gd install
```

2. Import godot resources
```
godot --headless --import
```
